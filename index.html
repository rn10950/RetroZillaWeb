RetroZilla

RetroZilla is a fork of Gecko 1.8.1 for improved compatibility on the modern web, with Windows 95 and Windows NT 4.0 in mind. Right now, RetroZilla's rendering capabilities are pretty similar to Firefox 2.0's, but as RetroZilla progresses, so will its capabilities.

Right now, I am focusing on RetroZilla Suite, a build of SeaMonkey/Mozilla Suite, because the suite provides both a browser and an email client in one package, along with other utilities. As RetroZilla progresses,it may also provide builds of Firefox and Thunderbird. The Firefox code is already in the tree, and if there's popular demand, i will copy over the Thunderbird code for personal builds.

Supported Operating Systems:

  • Windows 95
  • Windows 98
  • Windows ME
  • Windows NT 4.0
  • Windows NT 3.51 *
  • Windows 2000/XP/Vista/7/8.x/10/11 **

* - Please read NT 3.51 section below.

** - RetroZilla will run on modern versions of Windows, however it is not extensively tested on anything beyond Windows 2000 and XP. RetroZilla should install on 64-bit Windows as normal using WoW64, however a 64-bit native version will not be officially built. Bugs exclusively found on modern Windows versions will be considered very low priority. You'd better use modern Firefox or Google Chrome if compatible with your OS.

Windows NT 3.51

The RetroZilla GUI installer does not work on Windows NT 3.51, you must use the ZIP archive. Extract the archive to a location of your choosing and run retrozilla.exe. The following additional components must be installed on your system:

  • msvcrt.dll must be present in your PATH variable
  • oleaut32.dll in your system32 directory must be version 2.40.4275 or above. If you have an older version, you can install
    Microsoft Libraries Update Version 2

After verifing the above components installed, please reboot your PC. RetroZilla should then be able to run from the extracted directory. Profiles are created under %WINDIR%\RetroZilla.

Add-Ons

RetroZilla is compatible with add-ons for SeaMonkey 1.19. Eventually, RetroZilla-specific add-ons will be created and posted on this website. RetroZilla supports NPAPI plugins.
